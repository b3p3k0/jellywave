Now playing

Polls the station's public now-playing feed and writes the current track, DJ, show and what is up next into the live item's description. Clients show it when they reload the list or start playback; the playing bar keeps what it copied at playback start unless the station page below is active.
Downloads the cover from the station on every track change and saves it as the live item's image. Tracks without art, and this box unticked, show the station logo instead. The tile in the My Media row always keeps the logo.

Who can see it

Jellyfin's own Channel Access setting on each user (Dashboard → Users → user → Access) decides who sees the station. The button below adds the station once to every user who cannot see it yet, and never removes it from anyone; nothing else in a user's policy changes, and users whose block list names the station stay blocked. Users whose policy allows all channels (Jellyfin's default for new users) see it automatically. Users created later by a provisioning tool need the station in that tool's template, or another press of the button. To hide the station from one user, untick it on their Access page; the plugin will not undo that.
Save the station settings first.

Station page

Optional. With the File Transformation plugin installed (repository https://www.iamparadox.dev/jellyfin/plugins/manifest.json), users who can see the channel get a live header on the channel's page in the web client, Android app included: cover, track, DJ, show, what is next, play and stop, and a request box. Without it the tile keeps working; only the page is missing.
