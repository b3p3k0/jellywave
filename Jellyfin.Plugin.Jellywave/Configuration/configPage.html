Station

SUB/WAVE as reached from this Jellyfin server, e.g. http://your.host:7700. No trailing slash.
Reads the station name, tagline and stream format from the station's public API and fills the fields below.
Shown in My Media. Renaming creates a new channel entry; the old one is cleaned up by the "Refresh Internet Channels" task.
Optional channel description.

Stream

Mount under the base URL, normally /stream.mp3.
Relay works for every client that can reach Jellyfin and uses ffmpeg. Direct needs every client to reach the station.
Stream URL as clients see it. Leave empty to use the base URL and stream path.
Filled by "Fetch from station". Used to describe the stream to clients, not to transcode.

Now playing

Polls the station's public now-playing feed and writes the current track, DJ, show and what is up next into the live item's description, and the track as its album line. Clients show it when they reload the list or start playback.
Downloads the cover from the station on every track change and saves it as the live item's image. Tracks without art, and this box unticked, show the station logo instead. The tile in the My Media row always keeps the logo.
5 to 300. Tracks change every few minutes, so 20 is plenty.

Who can see it

Jellyfin shows a channel only to users whose policy allows all channels or lists this one. With this on, the plugin adds this channel to each user's channel list: now, at startup, and whenever a user is created or a user's policy is saved. It never changes anything else in a user's policy, and users with an explicit block list stay blocked. Turning it off stops future grants and removes nothing. While it is on, un-ticking this channel on one user's policy is undone on save; to exclude a user, put the channel in that user's block list.
Save first; the pass also runs automatically after saving with the box ticked.
