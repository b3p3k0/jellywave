Internet radio in a "Live Radio" tile in My Media.

Stations

Each enabled station is one item in the tile, in this order. SUB/WAVE stations get now playing, covers, likes, lyrics, schedule and requests; plain streams get a name, a logo, a genre, a website link and the title they send (on the station page). Every station plays through this Jellyfin server, which relays it to each listener with ffmpeg. Jellyfin checks each saved station: one it refuses is left out of the tile, with the reason. Changes take effect when you press Save. Reload status also asks each SUB/WAVE station once: one that nobody listens to is not asked otherwise.
⚠ Tile access only hides the tile. On Jellyfin 12.4, any signed-in user can still read every station's address and play it through Jellyfin's own API. Anyone who has a station's item id can play it without signing in. Jellyfin works this way for all media, not only Jellywave. Don't add private streams, or addresses that contain passwords or keys.

      Who can see it

      Users see all the stations or none; set it per user under Dashboard → Users → Access, where Jellyfin calls the tile a channel. The button adds the tile for everyone who doesn't have it, including anyone you switched off on purpose.

      Live panel

      Optional. Install File Transformation to get a live panel on the tile's page. Everything else works without it.

      Now playing

      SUB/WAVE stations: while someone plays one or has its station page open, the server keeps its item's description on the current track, DJ, show and what's next (most apps show it when the list is reopened), and the station page shows the live track; otherwise the server asks the station nothing and its item shows its own picture and text. Plain streams: while someone plays one, the server reads the title it sends every 15 seconds for the station page, each time a short extra listener on the station.
      Uses each track's cover as the station's picture. Without it, or when a track has no art, the Jellywave logo shows. The My Media tile always shows the logo.
